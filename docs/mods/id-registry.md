# Id registry

Every custom id in use, and the blocks to take new ids from. **Record a new id here in the same commit that adds it.**
This page replaces the `docs\MODULE_FRAMEWORK.md` registry that the module docs mention but that isn't in the pack.

Checked 2026-09-28 by scanning the `custom\` folders and modules.
